# London Crime Analysis

## Overview
This project analyses crime patterns across London using socio-economic, spatial, and time series methods.

## Objectives
- Analyse crime variation across boroughs
- Evaluate socio-economic factors
- Apply machine learning models
- Perform geospatial analysis
- Forecast crime trends

## Data Sources
- Metropolitan Police Service
- London Datastore
- Office for National Statistics

## Methods Used
- Exploratory Data Analysis (EDA)
- Machine Learning (Linear Regression, Random Forest, Gradient Boosting)
- Time Series Analysis (SARIMA, Holt-Winters)
- Geospatial Analysis (Moran’s I, LISA)

## Key Findings
- Socio-economic factors have limited explanatory power
- Crime is strongly spatially clustered
- Time series models capture trends but struggle at local level

## Tools & Libraries
- Python (Pandas, NumPy, Matplotlib)
- Scikit-learn
- Statsmodels
- GeoPandas
